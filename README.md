## 操作手順

1. Tweet一覧画面でユーザーの名前をクリックし、followボタンの下に表示されるブロックするボタンを押す（自分には表示されない）.
2. 画面上部のナビゲーションの「ブロック一覧」をクリックするとブロックしたユーザー画面に移動する．ブロックしたユーザー画面では ユーザー名とブロック解除ボタンが表示される．（データは中間テーブルに入る）
3. Tweet一覧画面ではブロックしたユーザーの投稿は表示されない．
4.  ブロックされたユーザーはブロックしたユーザーの詳細画面に移動しても、その人のマイページは表示されない.

## 工夫した点

- ブロックされたことをわかりやすくするために、Tweet検索画面には、ブロックされてもブロックした人の投稿が表示されるようにした。
- フォロー機能のシステムと類似しているブロック機能をテーマとして選んだ。
